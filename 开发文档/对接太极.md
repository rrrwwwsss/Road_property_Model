# 二.提交数据库.py
1. insert_object 方法：输入表结构类对象和要插入的表名，将数据插入数据库中
2. insert_databaser方法：获取模型识别的相关数据，并插入数据库中。需要传字典，包含result.csv字段、TJ_NAME（违法行为介绍）、 "MEASURE"（职权编码）
        "UNIT_CODE"（辖区编码）OffsiteRule_id(违法行为的id)
3. 在模型运行之前,先把六个违法行为都插入OFFSITE_RULE表,后面监测出行为就不用再插入了
```python
    if IS_SUBMIT == True:
        print("开始提交六项违法行为到数据库")
        # 先把六个违法行为存储到数据库中，后面就不用存了
        for k, v in VIOLATION_DICT.items():
            print(k, v)
            try:
                # 插入OFFSITE_RULE表
                offsiteRule = OffsiteRule(ID=v, QUESTION_NAME=k,
                                          CREATE_TIME=CREATE_TIME,
                                          UPDATE_TIME=UPDATE_TIME,
                                          IS_DEL="0",
                                          MEASURE=data['MEASURE'])
                insert_object(offsiteRule, table_name='OFFSITE_RULE')
            except Exception as e:
                print(e)
        import 数据库配置
        数据库配置.IS_SUBMIT = True  # 这样才修改了模块的全局变量
```
