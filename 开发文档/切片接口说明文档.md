一、API基础信息
服务器地址：http://localhost:18000

二、图片信息
1、id #主键id
2、name #图片名称file_name，格式为camera_camera_id_current_time.jpg，类型为text
3、capture_time #截帧时间，类型为text
4、belong_team #所属支队，类型为text
5、location #地点，即图片对应摄像头点位，类型为text
6、area_number #辖区编码，类型text
7、is_deleted #是否删除，指对应图片文件是否已经在文件夹中删除，类型为integer，0为否，1为是
8、image_path #图片所在路径，指图片所存放的文件夹，类型为text
9、account_name #账号名称，从配置导入,类型为text
10、violation_type #可能存在的违法类型，指某点位可识别的违法行为，类型text
11、camera_id #摄像头id,由点位csv读取，类型text
12、is_detected #获取状态，指图片是否已经被大模型识别，类型integer，0为否，1为是

三、接口详情
1、获取未处理图片信息

（1）请求： 
POST /images
Content-Type: application/json

（2）请求体：
{
    "violation_type": "string"
}
参数名violation_type，类型string，指违法行为类型

（3）响应：

    #成功（200 OK）：
    [
    {
        "id": 1,
        "name": "camera_11000000001319309175_20260113_212720.jpg",
        "capture_time": "20260113_212720",
        "belong_team": "九支队-房山执法队",
        "location": "G234兴阳线K402+010兴阳线坟庄村非限全景",
        "area_number": "110111",
        "image_path": " /data1/qwen2v/wjr_test/screenshots/camera_11000000001319309175_20260113_212720.jpg",
        "account_name": "USER_NAME",
        "violation_type": "擅自占用、挖掘公路",
        "camera_id": "11000000001319309175"
    },
    // ... 更多图片信息
    ]

    #无数据 (404 Not Found):
    {
    "detail": "未找到类型为 '擅自占用、挖掘公路' 的未处理图片"
    }

    #服务器错误 (500 Internal Server Error)：
    {
    "detail": "查询失败: [错误信息]"
    }

（4）示例：
curl -X POST "http://localhost:18000/images" \
  -H "Content-Type: application/json" \
  -d '{"violation_type": "擅自占用、挖掘公路"}'

2.标记图片为已处理

（1）请求：
POST /feedback
Content-Type: application/json

（2）请求体：
{
    "violation_type": "string",
    "name_list": ["string", "string", ...]
}
参数violation_type，类型string，指违法行为类型，必须与获取时一致
参数name_list，类型array[string]，指已处理的图片文件名列表

（3）响应：
    成功（200 OK）：
    {
    "message": "更新成功",
    "updated_count": 2
}
    空列表 (200 OK)：
    {
    "message": "图片列表为空"
}
    服务器错误 (500 Internal Server Error)：
    {
    "detail": "更新失败: [错误信息]"
}

（4）示例：# 标记图片为已处理
curl -X POST "http://localhost:18000/feedback" \
  -H "Content-Type: application/json" \
  -d '{
    "violation_type": "擅自占用、挖掘公路",
    "name_list": [
      "camera_11000000001319309175_20260113_212720.jpg",
    ]
  }'

3.检查是否正常
（1）请求：GET /health
（2）响应：{
    "status": "ok",
    "message": "服务正常运行"
}
（3）示例：# 检查服务状态
curl "http://localhost:18000/health"
