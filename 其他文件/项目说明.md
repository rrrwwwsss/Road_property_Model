# 公路违法行为识别系统交接说明

## 1. 项目用途

本系统用于识别道路监控图片中的疑似公路违法行为，并将线索图片和结果保存、上报。当前支持：占用挖掘公路、堆放物品、摆摊设点、悬挂物、移动井盖和设置非公路标志等六类行为。

项目分为两部分：

- 主识别服务：在总队服务器运行，负责获取图片、调用大模型识别、保存结果和上报。
- `clue_ui_sandbox`：我们自己的线索查看界面，供人工查询、查看图片和提交线索。

## 2. 主要目录

```text
main.py                  # 主服务启动文件
config/                  # 服务地址、数据库、路径等配置
prompts/                 # 六类违法行为的提示词
detectors/               # 各类违法行为识别逻辑
services/                # 图片获取、模型调用、数据库提交等服务
pic/                     # 运行产生的图片和本地 SQLite 数据库
clue_ui_sandbox/         # 线索管理界面前后端
其他文件/docker配置/     # 主识别服务 Docker 部署文件
其他文件/开发文档/       # 接口、太极对接、模型服务器等补充文档
```

## 3. 服务运行方式

主服务启动后会持续从图片切片接口获取待识别图片，调用联通服务器上的视觉大模型进行识别。

- 识别结果图片保存在 `/data1/qwen2v/pic/` 目录下对应的违法类型文件夹。
- 线索结果会写入本地 SQLite 数据库和 `result.csv`。
- 图片预览服务端口为 `5000`，访问格式为：

```text
http://<服务器IP>:5000/preview/<文件夹>/<图片名>
```

- 主服务会每天清理超过 10 天的原图。
- 主服务在每日 21:45 至次日 06:15 不执行模型识别。

## 4. 主服务部署与更新

总队服务器上的主服务代码目录为：

```text
/data1/qwen2v/road_property_rightsmodel/
```

代码通过 Docker 卷挂载到容器。修改代码后，将文件同步到对应目录，再执行：

```bash
cd /data1/qwen2v
docker compose restart debris-detector
```

查看主服务日志：

```bash
docker logs -f --tail 100 debris-detector
```

应用日志保存在容器代码目录下的 `logs/` 中。

如果修改了 `docker-compose.yml`、端口或目录挂载，不能只执行 `restart`，应执行：

```bash
docker compose up -d --force-recreate
```

主服务镜像和 Compose 配置见 `其他文件/docker配置/`；详细 Docker 操作见 `其他文件/开发文档/docker部署说明.md`。

## 5. 线索管理界面

线索界面位于 `clue_ui_sandbox/`：

- 前端访问端口：`6586`
- 后端接口端口：`6587`
- 后端健康检查：`http://<服务器IP>:6587/healthz`

界面读取主服务生成的 SQLite `results` 表，可查看线索列表、统计数据、详情和图片，也可人工提交线索。

界面部署、更新及故障排查见：`clue_ui_sandbox/README.md`。

## 6. 日常检查

1. 使用 `docker ps` 确认 `debris-detector` 容器正常运行。
2. 使用 `docker logs -f --tail 100 debris-detector` 查看是否持续出现“开始轮询”等日志。
3. 检查 `pic` 目录是否持续产生识别图片和数据库记录。
4. 检查 `5000` 端口是否可正常预览图片。
5. 如没有识别结果，依次检查图片切片服务、模型服务和网络连接。

## 7. 重要配置与注意事项

- `config/配置.py`：模型地址、图片接口、图片目录、去重时间等主配置。
- `config/数据库配置.py`：太极数据库及违法类型映射。
- `config/prompts.json` 和 `prompts/`：各类行为的识别提示词。
- 配置文件含有账号、密码和服务器地址等敏感信息，交接时不要复制到聊天记录、文档或代码仓库。
- 修改提示词或识别逻辑后，应先用测试图片验证，再部署到生产环境。
- `其他文件/未合并到总模型的模块/` 为历史/测试代码，日常运行无需修改。
