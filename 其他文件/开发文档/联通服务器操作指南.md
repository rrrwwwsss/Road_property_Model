## 对于原来的 Qwen2.5-72B 模型的容器停止和重启

使用 `docker ps` 命令查看当前运行的容器，使用 `docker ps -a` 命令查看所有容器（包括已停止的容器）。

使用 `docker stop <容器ID>` 和 `docker start <容器ID>` 来停止或启动容器。

容器重启后不会自动启动服务，需要进入容器：

```bash
docker exec -it <容器ID> /bin/bash
```

执行以下命令：

```bash
cd /usr/local/Ascend/mindie/latest/mindie-service/
./bin/mindieservice_daemon
```

等待十分钟左右，出现 `Daemon start success!` 就可以了。

此时不要按 Ctrl + C 退出，应该使用以下方式：

1. 按下 Ctrl + Z 挂起进程；

2. 输入命令 `bg` 转入后台运行；

3. 输入命令 `disown -h` 剥离终端归属，告诉 Shell 退出时不要杀掉这个任务；

4. 此时输入 `exit` 可以安全退出。

## 检查服务状态

输入命令 `netstat -tunip | grep <端口号>` 可以查看指定端口是否有容器在监听：

```text
tcp        0      0 192.168.0.161:2025      0.0.0.0:*               LISTEN      1186856/./bin/mindi
```

输入 `npu-smi info` 可以查看 NPU 是否有负载：

```text

+===========================+===============+====================================================+

+===========================+===============+====================================================+
| 4       0                 | 1187717       | mindie_llm_back          | 49704                   |
+===========================+===============+====================================================+
| 5       0                 | 1187720       | mindie_llm_back          | 49706                   |
```

目前测试到的是：

- 监听端口 1025 的服务运行在 NPU 0-3，容器名为 Qwen2.5-VL-72B-03
- 监听端口 2025 的服务运行在 NPU 4-7，容器名为 Qwen2.5-VL-72B-04

## 使用 vllm-ascend 镜像部署 Qwen3-VL-30B-A3B-Instruct 模型

参考资料：[Qwen3-VL-30B-A3B-Instruct](https://docs.vllm.ai/projects/vllm-ascend-cn/zh-cn/latest/tutorials/Qwen3-VL-30B-A3B-Instruct.html#)

镜像已经导入到了服务器上，名称和标签为：

```text
quay.io/ascend/vllm-ascend:v0.14.0rc1
```

后台启动容器：

```bash
export IMAGE=quay.io/ascend/vllm-ascend:v0.14.0rc1

docker run --name Qwen3-VL-30B-A3B-Instruct-04 \
--restart unless-stopped \
--shm-size=1g \
--net=host \
--device /dev/davinci4 \
--device /dev/davinci5 \
--device /dev/davinci_manager \
--device /dev/devmm_svm \
--device /dev/hisi_hdc \
-v /usr/local/dcmi:/usr/local/dcmi \
-v /usr/local/bin/npu-smi:/usr/local/bin/npu-smi \
-v /usr/local/Ascend/driver/lib64/:/usr/local/Ascend/driver/lib64/ \
-v /usr/local/Ascend/driver/version.info:/usr/local/Ascend/driver/version.info \
-v /etc/ascend_install.info:/etc/ascend_install.info \
-v /data01/HTC/gxh/Models:/root/Models \
-v /data:/data \
-v /data01/HTC/gxh/media:/media \
-itd $IMAGE \
bash -c "tail -f /dev/null"
```

然后使用 `docker exec -it <容器ID> /bin/bash`进入容器。若顺利，将进入容器的`/workspace`目录。

设置容器内环境变量：

```bash
export VLLM_USE_MODELSCOPE=True
export PYTORCH_NPU_ALLOC_CONF=max_split_size_mb:256
export VLLM_USE_V1=0
```

使用绝对路径加载模型、设置端口和模型名：

```bash
vllm serve /root/Models/Qwen3-VL-30B-A3B-Instruct \
--tensor-parallel-size 2 \
--enable-expert-parallel \
--limit-mm-per-prompt.video 0 \
--max-model-len 128000 \
--trust-remote-code \
--port 2025 \
--served-model-name Qwen3-VL-30B-A3B-Instruct
```

等待一段时间，直到出现：

```text
INFO:     Started server process [746077]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
```

此时模型加载完成，使用 Ctrl + D 离开容器。

更便捷的启动命令：

```bash
docker run -d \
  --name Qwen3-VL-30B-A3B-Instruct-04 \
  --restart unless-stopped \
  --net=host \
  --shm-size=20g \
  --device /dev/davinci4 \
  --device /dev/davinci5 \
  --device /dev/davinci_manager \
  --device /dev/devmm_svm \
  --device /dev/hisi_hdc \
  -v /usr/local/dcmi:/usr/local/dcmi \
  -v /usr/local/bin/npu-smi:/usr/local/bin/npu-smi \
  -v /usr/local/Ascend/driver/lib64/:/usr/local/Ascend/driver/lib64/ \
  -v /usr/local/Ascend/driver/version.info:/usr/local/Ascend/driver/version.info \
  -v /etc/ascend_install.info:/etc/ascend_install.info \
  -v /data01/HTC/gxh/Models:/root/Models \
  -v /data:/data \
  -v /data01/HTC/gxh/media:/media \
  $IMAGE \
  vllm serve /root/Models/Qwen3-VL-30B-A3B-Instruct \
  --tensor-parallel-size 2 \
  --enable-expert-parallel \
  --limit-mm-per-prompt.video 0 \
  --max-model-len 128000 \
  --trust-remote-code \
  --port 2025 \
  --served-model-name Qwen3-VL-30B-A3B-Instruct
```
