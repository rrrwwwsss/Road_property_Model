# 第一步：创建脚本文件
```bash
# 创建并编辑脚本文件
vi /usr/local/bin/deploy_mindie.sh
# 按 i 键进入插入模式（可以看到左下角显示 -- INSERT --）
# 然后粘贴或输入脚本内容

# 编辑完成后：
1. 按 Esc 键退出插入模式
2. 输入 :wq 然后按 Enter（保存并退出）
   # :wq 含义：
   # :   进入命令行模式
   # w   write（保存）
   # q   quit（退出）
```
# 第二步：设置权限并配置cron
```bash
chmod +x /usr/local/bin/deploy_mindie.sh
ls -l /usr/local/bin/deploy_mindie.sh #验证是否成功
```
# 第三步：设置权限并配置cron
```bash
crontab -e
# 1.输入这个命令并回车

# 2.如果是第一次运行，系统会问您选择编辑器：
# 选择 1 (nano) 或 2 (vim)，推荐选 1 (nano)
# 或者直接回车选择默认的

# 3.在打开的文件中，移动光标到最后一行

# 4.复制下面其中一行（选一个方案）粘贴进去：
0 22 * * * /usr/local/bin/deploy_mindie.sh
0 6 * * * /usr/local/bin/deploy_mindie.sh

# 5.验证是否成功
# 查看当前的定时任务
crontab -l
```
